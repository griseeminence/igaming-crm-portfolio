## Principles I work by
1. **A campaign is worth exactly what it caused.** I count the difference against a random control group. The number of responders on its own says nothing.
2. **Money decides.** I look at incremental NGR after bonus and channel costs. Opens, clicks and the number of bonuses claimed are supporting numbers.
3. **A metric change is a symptom.** First understand the cause, then decide what to send.
4. **Behaviour, not the calendar.** A journey starts with a player's action and ends when the player reaches the goal.
